# Task Manager 📋

Минималистичный менеджер задач с темной темой, разработанный на PHP.

## 🚀 Особенности

- Современный минималистичный дизайн с темной темой
- Полная аутентификация пользователей
- CRUD операции для задач
- Система приоритетов (низкий, средний, высокий)
- Статусы задач (в работе, выполнено)
- Статистика и аналитика
- Адаптивный дизайн
- PSR-4 автозагрузка через Composer

## 🛠 Технологии

- **Backend**: PHP 8.0+
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: MySQL
- **Architecture**: MVC
- **Autoloading**: Composer PSR-4
- **Styling**: Custom CSS (Minimal Dark Theme)
